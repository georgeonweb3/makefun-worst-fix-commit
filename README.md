One commit message, 100 characters max: the funniest commit message for a bug fix that made everything worse. The entry program writes the line to `/output/entry.txt`.

The line: *"fix: speed up checkout by caching prices in 2019 — checkout is instant, refunds are forever"* (91 characters)

Why this line: it reads as a real commit subject a tired engineer would type, the fix genuinely works (checkout is instant) which is exactly what makes it worse (every price is seven years stale, so every sale has to be refunded), and it ends on the punch — refunds are forever. It avoids the field's obvious angles (reverting, testing in production, breaking everything, deleting the thing to fix it) for a fresh one: a repair that succeeds too well.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
